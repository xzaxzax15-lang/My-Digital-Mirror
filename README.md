# مرآتي الرقمية — Digital Mirror

منصة عربية أولاً (RTL) للمساعدة في حوادث الأمن السيبراني والتوعية الرقمية — بهدوء، بلا لوم، وبخصوصية مصممة مسبقاً.

<p dir="rtl">
مساعد حوادث تعاطفي يصنّف الواقعة ويعطي خطة مرتبة (افعلها الآن / الخطوات التالية / بعد التعافي)، وأكاديمية توعية بـ13 درساً واختبارات، وأدوات خصوصية (فحص كلمات مرور محلي 100%، فحص تسريبات البريد بالبصمة فقط، تحليل روابط دون زيارتها)، وفحص ذاتي، ودليل موارد رسمية بحالات تحقق معلنة.
</p>

## المتطلبات

- Node.js ≥ 22.5 (يُفضَّل 24+ — يستخدم `node:sqlite` المدمج، بلا اعتماديات أصلية)
- npm ≥ 10

## التشغيل السريع

```bash
# 1) تثبيت الاعتماديات
npm install

# 2) نسخ إعدادات البيئة وتعديلها عند الحاجة (كل القيم اختيارية عدا الإنتاج)
cp .env.example .env

# 3) تطوير (API على :3000 + واجهة Vite على :5173 مع بروكسي)
npm run dev

# 4) بناء الإنتاج وتشغيله (خادم واحد يخدم الواجهة والـAPI)
npm run build
npm start            # http://localhost:3000
```

الوصول الافتراضي للوحة الإدارة: `http://localhost:3000/admin` — المستخدم من `ADMIN_USERNAME` (افتراضياً `admin` / `change-me-in-production`). **غيّرهما في الإنتاج عبر `.env`**.

## الاختبارات

```bash
npm test            # 85 اختباراً: التصنيف، المحرك، الروابط، SSRF، الـAPI، الإدارة، التقييم
npm run typecheck   # فحص أنواع الخادم والواجهة
```

## متغيرات البيئة

انظر `.env.example` للشرح الكامل. أهمها:

| المتغير | الوصف |
|---|---|
| `SESSION_SECRET` | توقيع جلسات الإدارة — طويل وعشوائي في الإنتاج |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | حساب مدير المحتوى (يُنشأ عند أول تشغيل) |
| `HIBP_API_KEY` | مفتاح Have I Been Pwned (مدفوع) لفحص التسريبات — بدونه تظهر الأداة «غير متاحة» بصدق |
| `AI_PROVIDER` / `AI_API_KEY` / `AI_MODEL` | مزود ذكاء اصطناعي اختياري متوافق مع OpenAI — بدونه يعمل المساعد بمحرك الأدلة الموثقة بالكامل |

## البنية

```
shared/            الأنواع + المحتوى الموثق (19 دليلاً، 13 درساً، الموارد، التقييم)
  content/         playbooks*, lessons*, resources, videos, assessment, steps
  linkHeuristics   تحليل الروابط المشترك بين الخادم والواجهة
server/            Express API + الأمن + SQLite (node:sqlite)
  services/        assistant (المحرك الحتمي), classifier, ai (اختياري), breach
  db/              طبقة التخزين (إدارة فقط) + sqlite shim
client/            React + Vite (RTL) — صفحة لكل ميزة، أدوات محملة كسولاً
tests/             Vitest — 85 اختباراً
data/              قاعدة SQLite (تُنشأ تلقائياً، ليست في git)
docs/              ARCHITECTURE.md + REPORT.md
```

## مبادئ الخصوصية المنفذة

- **لا تُخزَّن محادثات المساعد إطلاقاً** — تبقى في المتصفح، وزر «محادثة جديدة» يمسحها
- **كلمات المرور لا تغادر المتصفح** — zxcvbn محلي + فحص Pwned Passwords الاختياري بـ k-anonymity (بادئة 5 أحرف من SHA-1 فقط)
- **بريدك لا يصلنا** — SHA-1 يُحسب في المتصفح ويُرسل فقط، بلا تسجيل ولا تخزين
- تحليل الروابط محلي بالكامل ولا يزور أي رابط
- ترويسات أمان صارمة (CSP بلا سكربتات خارجية)، تحديد معدل، CSRF للإدارة، سجل تدقيق، درع SSRF لجلب المصادر

## حدود معلنة (بصدق)

- فحص التسريبات يعمل فقط عند توفير `HIBP_API_KEY` — وإلا يظهر «غير متاحة» بلا نتائج وهمية
- «لم يُعثر عليه» لا تعني «آمن» — مكتوبة صراحة في الواجهة
- معظم روابط الموارد في انتظار التحقق الآلي من لوحة الإدارة (زر «تحقق») — حالتها معروضة للمستخدم بشفافية
- التقييم الذاتي تقييم عادات، وليس تدقيقاً جنائياً
