## قرارات معمارية جوهرية

### 1) المحتوى كودٌ موثق لا صفوف قاعدة بيانات
الأدلة الإرشادية (19)، الدروس (13)، الموارد، والتقييم تعيش في `shared/content` كملفات TypeScript
منمة الأنواع. أسباب: مراجعة الكود، الإصدارات (git)، والاختبارات تغطي المحتوى نفسه.
قاعدة البيانات تحتفظ فقط بطبقة الإدارة: حالات النشر/الإخفاء، تواريخ التحقق، الموارد والفيديوهات
المضافة، حساب المدير، وسجل التدقيق — وتُدمج فوق المحتوى عند الطلب (`mergeContent`).

### 2) المساعد حتمي أولاً، الذكاء الاصطناعي تحسين اختياري
- التصنيف: مطابقة إشارات كلمية على نص عربي مطبَّع (توحيد الهمزات/التاء/التشكيل) مع ترجيح
  للعبارات المركبة، وكشف الغموض بين تصنيفين متقاربين بسؤال فارق واحد.
- الاستعجال: طبقات — خطر جسدي → حرج فوراً؛ إشارات ابتزاز/مال نشط → حرج؛ أثر مالي → عالي؛
  وإلا افتراضي الدليل. يعاد التقييم مع كل رسالة ولا يهبط أبداً (max مع الحالة السابقة).
- الخطة: تُبنى دوماً من الـPlaybook الموثق وتُدمج خطوات «فقدان/امتلاك التحكم» بحسب إجابة المستخدم.
- الذكاء الاصطناعي (اختياري): يعيد صياغة الرسالة التعاطفية فقط؛ كائن الخطة المنظم يبقى من
  المحرك. فشله أو غيابه = تجربة كاملة بلا أي خداع.

### 3) الخصوصية بالتصميم في كل أداة
- كلمة المرور: لا تخرج من المتصفح إطلاقاً. الفحص الاختياري للتسريبات يرسل بادئة SHA-1 (5 أحرف)
  مباشرة إلى api.pwnedpasswords.com وفق k-anonomity، مفصوح عنه في الواجهة، ويفشل بصمت.
- بريد التسريبات: SHA-1 يُحسب في المتصفح؛ خادمنا يمرره فقط (المزود يتطلب مفتاحاً سرياً) دون أي
  تسجيل أو تخزين، مع حد 3 طلبات/5 دقائق لكل IP.
- سجلات الخادم: لا تُسجل نصوص المستخدمين؛ تُسجل بيانات تشغيلية فقط (نوع الحادثة كفئة، الاستعجال،
  المدة) — إضافة إلى دالة redact() لأي نص عرضي.

### 4) درع SSRF (safeFetch)
http/https فقط؛ منع localhost/.local/.internal وعناوين metadata؛ حل DNS وفحص كل العناوين ضد
النطاقات الخاصة (v4+v6) قبل الطلب؛ redirect: error؛ مهلة وحجم أقصى وفحص content-type؛
stripHtml يعامل الصفحات كبيانات غير موثوقة. التحقق من الموارد للمشرفين يستخدم نفس الدرع.

### 5) الواجهة RTL أولاً
dir=rtl على المستند، خصائص CSS منطقية (margin-inline-start…) في كامل نظام التصميم، خطوط
نظام عربية بلا تحميل خارجي (CSP بلا أصول خارجية)، خطوط تركيز مرئية، skip-link، aria-live
للمحادثة، reduced-motion. الحزمة الرئيسية 262KB (83KB gzip) والقواميس الثقيلة (1.6MB)
تُحمَّل كسولاً عند فتح أداة كلمات المرور فقط.

## قاعدة البيانات (node:sqlite)
جداول: admins, audit_log, content_status (PK مركب: نوع+معرف), resource_verifications,
custom_resources, custom_videos. Migrations تنفذ تسلسلياً عند الإقلاع (كود داخل Store).
ملاحظة توافق: `server/db/sqlite.ts` جسر عبر createRequire لأن أدوات البناء الأقدم لا تعرف
`node:sqlite` كوحدة مدمجة.

## حدود معروفة ومسارات تطوير
- البحث الحي في المصادر (research connector) البنية جاهزة (allowlist + safeFetch) لكن لا يوجد
  مزود بحث مهيأ افتراضياً — RESEARCH_ENABLED=false. الاستشهادات الحالية من المحتوى المنسق فقط.
- لغة إنجليزية ثانية: البنية جاهزة (المحتوى مفصول عن العرض) لكن لم تُترجم الواجهة بعد.
- مصادقة ثانية للمحررين (role editor موجود في المخطط، بلا واجهة إضافة مستخدمين بعد).
