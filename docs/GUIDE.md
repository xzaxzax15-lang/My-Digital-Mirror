## 5) كيف تضيف نوع حادثة جديد (دليل للمساعد)؟

1. افتح الملف المناسب: حادثة مال → `playbooks-money.ts`، جهاز → `playbooks-devices.ts`... أو أنشئ ملفاً جديداً على نفس النمط وأضفه إلى `playbooks-index.ts`.
2. القالب:

```ts
{
  id: "new_incident",                 // معرف فريد بالإنجليزية وشرطات سفلية
  title: "اسم الحادثة بالعربية",
  category: "المال والاحتيال",        // تظهر كتصنيف
  defaultUrgency: "medium",           // low / medium / high / critical
  signals: ["كلمة يدخلها المستخدم", "عبارة شائعة", "english word"],  // مفتاح التصنيف — اكتب الكثير منها
  criticalSignals: ["عبارة ترفع الحالة إلى طارئة"],                    // اختياري
  clarifyingQuestions: ["سؤال توضيح أول", "سؤال توضيح ثانٍ"],
  steps: {
    now: [
      s("ماذا يفعل الآن", "لماذا ينفع", "كيف يتأكد أنها نجحت", "ماذا يفعل إن لم تنجح"),
    ],
    next: [ s("...", "...", "...", "...") ],
    after: [ s("...", "...", "...", "...") ],
  },
  officialLinks: [
    { title: "رابط رسمي", publisher: "الجهة", url: "https://...", status: "pending" },
  ],
  doNot: commonDoNot(),   // التحذيرات المشتركة، أو اكتب قائمة خاصة
},
```

3. **أهم نقطة:** حقل `signals` هو ما يربط كلام المستخدم بالدليل. اكتب كل الصيغ العامية المحتملة (مثال: "مسحوب"، "انسرق"، "اخترق"، "hacked") — وأيضاً أضف الكلمات الجديدة في `CYBER_SCOPE_WORDS` داخل `server/services/classifier.ts` إن كانت خارج النطاق القديم.
4. شغّل `npm test` — اختبار «الخطوات الرباعية» سيتحقق أن كل خطوة كاملة، واختبار التصنيف سيتأكد من الأدلة.

> **اختبار سريع للتصنيف:** أرسل للمساعد جملة وكأنك مستخدم، وتأكد أنه يصنّف الحادثة الصحيحة.

## 6) كيف تضيف قناة رسمية أو مادة مرئية؟

### الطريقة السهلة (من لوحة الإدارة — بدون كود):
1. افتح `/admin` وسجّل الدخول (البيانات من `.env`، الافتراضي `admin` / `change-me-in-production`).
2. **قناة رسمية:** املأ العنوان والرابط والفئة والوصف → «إضافة ونشر» → اضغط زر «فحص» بجانبها ليفحص الرابط فعلياً ويثبت تاريخ الفحص (إن نجح الوصول فقط).
3. **مادة مرئية:** املأ العنوان والرابط والمصدر → «إضافة ونشر». **راجع الرابط بنفسك قبل النشر** — لا نعلّم أي مادة بأنها موثوقة تلقائياً.

### بالكود (للعناصر الأساسية):
- قنوات: `shared/content/resources.ts` — انسخ كائناً مشابهاً وغيّر البيانات. من يريد حالة `verified` فليكن عبر فحص حقيقي من لوحة الإدارة.
- مواد مرئية: `shared/content/videos.ts` — أضف `verifiedAt` **فقط إذا فحصت الرابط بنفسك يومياً بتاريخه**.

## 8) لوحة الإدارة — ماذا تفعل وكيف؟

- **الدخول:** `/admin` → اسم المشرف وكلمة المرور من `.env`.
- **نشر/إخفاء درس أو قناة:** جدول العناصر → زر «إخفاء» أو «نشر» — التأثير فوري على الموقع العام.
- **فحص رابط قناة:** زر «فحص» يجرب الوصول عبر وسيط آمن (يمنع الشبكات الداخلية) ويثبت تاريخ الفحص عند النجاح فقط. الرابط الذي لم يُفحص يظهر للمستخدمين بوسم «لم يُفحص بعد» — بصدق.
- **سجل الإجراءات:** آخر 50 عملية باسم المشرف ووقتها — لا يُسجل فيها أي محتوى من المستخدمين.
- **الأمان:** جلسة موقعة تنتهي بعد 8 ساعات + حماية CSRF تلقائية. لا تعطي بيانات `.env` لأحد.

## 9) متغيرات الإعدادات (.env) — أيها يهمك؟

| المتغير | متى تحتاجه |
|---|---|
| `ADMIN_PASSWORD` + `SESSION_SECRET` | دائماً قبل أي نشر حقيقي |
| `HIBP_API_KEY` | لتشغيل فحص تسريبات البريد (اشتراك مدفوع من haveibeenpwned.com) — بدونه الأداة تعرض «غير مفعّلة» بصدق |
| `AI_PROVIDER=openai-compatible` + `AI_BASE_URL` + `AI_API_KEY` + `AI_MODEL` | فقط إن أردت صياغة أجمل لردود المساعد — بدونها يعمل المساعد كاملاً بمحركه المحلي (لا شيء ينكسر) |
| `PORT` | غيّر 3000 لو مشغول |

> فحص كلمات المرور وفحص الروابط والفحص الذاتي تعمل **بدون أي مفتاح** — محلية بالكامل.

## 10) ما لا تستطيع المنصة فعله (لتكون واضحاً مع أي مستخدم)

- لا تسترد حسابات أو أموال — توجه للقنوات الرسمية فقط.
- «لا تسريب» في فحص البريد ≠ البريد نظيف — القاعدة لا تشمل كل التسريبات.
- الروابط الموسومة «لم يُفحص بعد» لم تُجرّب بعد — فحصها من لوحة الإدارة.
- لا يوجد إنجليزية بعد؛ البنية جاهزة لإضافة لغة ثانية لاحقاً.

## قرارات معمارية جوهرية

### 1) المحتوى كودٌ موثق لا صفوف قاعدة بيانات
الأدلة الإرشادية (19)، الدروس (13)، الموارد، والتقييم تعيش في `shared/content` كملفات TypeScript
منمة الأنواع. أسباب: مراجعة الكود، الإصدارات (git)، والاختبارات تغطي المحتوى نفسه.
قاعدة البيانات تحتفظ فقط بطبقة الإدارة: حالات النشر/الإخفاء، تواريخ التحقق، الموارد والفيديوهات
المضافة، حساب المدير، وسجل التدقيق — وتُدمج فوق المحتوى عند الطلب (`mergeContent`).

### 2) المساعد حتمي أولاً، الذكاء الاصطناعي تحسين اختياري
- التصنيف: مطابقة إشارات كلمية على نص عربي مطبَّع (توحيد الهمزات/التاء/التشكيل) مع ترجيح
  للعبارات المركبة، وكشف الغموض بين تصنيفين متقاربين بسؤال فارق واحد.
- الاستعجال: طبقات — خطر جسدي → حرج فوراً؛ إشارات ابتزاز/مال نشط → حرج؛ أثر مالي → عالي؛
  وإلا افتراضي الدليل. يعاد التقييم مع كل رسالة ولا يهبط أبداً (max مع الحالة السابقة).
- الخطة: تُبنى دوماً من الـPlaybook الموثق وتُدمج خطوات «فقدان/امتلاك التحكم» بحسب إجابة المستخدم.
- الذكاء الاصطناعي (اختياري): يعيد صياغة الرسالة التعاطفية فقط؛ كائن الخطة المنظم يبقى من
  المحرك. فشله أو غيابه = تجربة كاملة بلا أي خداع.

### 3) الخصوصية بالتصميم في كل أداة
- كلمة المرور: لا تخرج من المتصفح إطلاقاً. الفحص الاختياري للتسريبات يرسل بادئة SHA-1 (5 أحرف)
  مباشرة إلى api.pwnedpasswords.com وفق k-anonomity، مفصوح عنه في الواجهة، ويفشل بصمت.
- بريد التسريبات: SHA-1 يُحسب في المتصفح؛ خادمنا يمرره فقط (المزود يتطلب مفتاحاً سرياً) دون أي
  تسجيل أو تخزين، مع حد 3 طلبات/5 دقائق لكل IP.
- سجلات الخادم: لا تُسجل نصوص المستخدمين؛ تُسجل بيانات تشغيلية فقط (نوع الحادثة كفئة، الاستعجال،
  المدة) — إضافة إلى دالة redact() لأي نص عرضي.

### 4) درع SSRF (safeFetch)
http/https فقط؛ منع localhost/.local/.internal وعناوين metadata؛ حل DNS وفحص كل العناوين ضد
النطاقات الخاصة (v4+v6) قبل الطلب؛ redirect: error؛ مهلة وحجم أقصى وفحص content-type؛
stripHtml يعامل الصفحات كبيانات غير موثوقة. التحقق من الموارد للمشرفين يستخدم نفس الدرع.

### 5) الواجهة RTL أولاً
dir=rtl على المستند، خصائص CSS منطقية (margin-inline-start…) في كامل نظام التصميم، خطوط
نظام عربية بلا تحميل خارجي (CSP بلا أصول خارجية)، خطوط تركيز مرئية، skip-link، aria-live
للمحادثة، reduced-motion. الحزمة الرئيسية 262KB (83KB gzip) والقواميس الثقيلة (1.6MB)
تُحمَّل كسولاً عند فتح أداة كلمات المرور فقط.

## قاعدة البيانات (node:sqlite)
جداول: admins, audit_log, content_status (PK مركب: نوع+معرف), resource_verifications,
custom_resources, custom_videos. Migrations تنفذ تسلسلياً عند الإقلاع (كود داخل Store).
ملاحظة توافق: `server/db/sqlite.ts` جسر عبر createRequire لأن أدوات البناء الأقدم لا تعرف
`node:sqlite` كوحدة مدمجة.

## حدود معروفة ومسارات تطوير
- البحث الحي في المصادر (research connector) البنية جاهزة (allowlist + safeFetch) لكن لا يوجد
  مزود بحث مهيأ افتراضياً — RESEARCH_ENABLED=false. الاستشهادات الحالية من المحتوى المنسق فقط.
- لغة إنجليزية ثانية: البنية جاهزة (المحتوى مفصول عن العرض) لكن لم تُترجم الواجهة بعد.
- مصادقة ثانية للمحررين (role editor موجود في المخطط، بلا واجهة إضافة مستخدمين بعد).

  كلمات المرور/الرموز، ومسح المحادثة بزر واحد — **ولا تُخزَّن أي محادثة على الخادم أصلاً**.

### 2) أكاديمية التوعية
- **13 درساً** كاملاً (هدف/شرح/أمثلة آمن-مزيف موسومة/اختبار بتفسيرات/قائمة تطبيق) على ثلاثة
  مسارات. الاختبارات تعمل بتفاعل كامل (صح/خطأ + تفسير + نتيجة + إعادة).
- مكتبة فيديو: عنصر واحد **تم التحقق من وجوده فعلاً اليوم** (قائمة تشغيل يوتيوب تعليمية بالعربية)
