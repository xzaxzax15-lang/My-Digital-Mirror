# تقرير التسليم — مرآتي الرقمية
**التاريخ:** 2026-10-26 · **الحالة:** يعمل (production build) · **الاختبارات:** 85/85 ✅

## الميزات المنفذة والفعّالة (وليست واجهات فارغة)

### 1) مساعد الحوادث (يعمل بلا أي مفتاح خارجي)
- مصنّف عربي يفرّق **19 نوع حادثة** (اختبار لكل نوع) مع تطبيع عربي (همزات/تشكيل/تاء) وكشف
  غموض بسؤال فارق، وسؤالان توضيحيان كحد أقصى قبل الخطة (كما في المواصفة).
- استعجال رباعي (حرجة/عالية/متوسطة/منخفضة) مع **سبب معروض** وإعادة تقييم مع كل رسالة؛
  الخطر الجسدي يعطي توجيه الطوارئ قبل أي شيء رقمي؛ ذكر قاصر في حوادث المحتوى الحميم → حرج +
  توجيه لقنوات حماية الطفل (Take It Down / CyberTipline).
- خطة من ثلاث مراحل (افعلها الآن/الخطوات التالية/بعد التعافي)، كل خطوة: ماذا/لماذا/كيف تتأكد.
  خطوات «فقدان التحكم» تُدمج وتتصدر مرحلة «الآن» عند فقدان الوصول (مُختبر).
- إعادة توجيه مهذبة بالعربية للمواضيع الخارجة عن النطاق (مُختبر)، وتحذير ثابت من إرسال
  كلمات المرور/الرموز، ومسح المحادثة بزر واحد — **ولا تُخزَّن أي محادثة على الخادم أصلاً**.
- محوّل AI اختياري (متوافق OpenAI) يحسّن الصياغة فقط؛ الخطة دائماً من المحتوى الموثق.

### 2) أكاديمية التوعية
- **13 درساً** كاملاً (هدف/شرح/أمثلة آمن-مزيف موسومة/اختبار بتفسيرات/قائمة تطبيق) على ثلاثة
  مسارات. الاختبارات تعمل بتفاعل كامل (صح/خطأ + تفسير + نتيجة + إعادة).
- مكتبة فيديو: عنصر واحد **تم التحقق من وجوده فعلاً اليوم** (قائمة تشغيل يوتيوب تعليمية بالعربية)
  بتاريخ تحقق معروض؛ البنية جاهزة لإضافة المزيد من لوحة الإدارة بعد التحقق — لا فيديوهات مزيفة.

### 3) الأدوات
- **فاحص كلمات المرور:** zxcvbn محلي 100% (يعمل دون إنترنت)، إظهار/إخفاء، مسح، نطاقات زمن
  تخمين بفرضيات معلنة + ترجمة عربية للتغذية الراجعة، وفحص اختياري عبر k-anonymity
  (بادئة 5 أحرف فقط إلى Pwned Passwords) يفشل بصمت.
- **فحص تسريبات البريد:** SHA-1 في المتصفح → بروكسي يمرر البصمة فقط إلى HIBP. بلا مفتاح:
  حالة «غير متاحة» صادقة (مُختبرة). «لم يُعثر» ≠ «آمن» — مكتوبة صراحة. حد 3/5دقائق (مُختبر).
- **محلل روابط ورسائل:** محلي، لا يزور الروابط، يكشف: انتحال علامات (13 علامة)، IP كمضيف،
  punycode، مختصرات، user:pass@، TLDs خطرة، سلاسل فرعية طويلة، شرطات، http، وأنماط احتيال
  نصية عربية. «لا علامات» لا تُعرض كأمان أبداً.

### 4) الفحص الذاتي
10 أسئلة × 4 خيارات متدرجة عبر 7 أبعاد، بمعايير تقييم معلنة قبل البدء؛ نقاط قوة، أولويات
تحسين مرتبة بالأضعف، خطة 7 أيام، وحفظ محلي اختياري بموافقة صريحة (localStorage) مع حذف.

### 5) دليل الموارد
23 مورداً رسمياً (استعادة حسابات/إبلاغ/CERT لدول عربية وخليجية/حماية مستهلك/تعليم) مصنفة
بفئة ودولة، **كل مورد يعرض حالة تحقيقه بصدق**: عنصران موثقان بتاريخ اليوم (تحققتُ منهما فعلياً
أثناء البناء: صفحة مركز البحرين + قائمة اليوتيوب)، والباقي «بانتظار التحقق» حتى يفعّلها المشرف
بزر «تحقق» (يستخدم درع SSRF ويثبت التاريخ عند نجاح الوصول فقط).

### 6) الإدارة
دخول (افتراضي من .env)، جلسة HMAC httpOnly + SameSite=Strict + CSRF إرسال مزدوج (مُختبر:
التعديل بلا رمز يُرفض 403)، إخفاء/نشر الدروس والموارد (مُختبر مع أثره الفعلي على الواجهة
العامة)، إضافة موارد وفيديوهات، تحقق الروابط، وسجل تدقيق كامل بلا محتوى ضحايا.

### 7) الأمن والخصوصية (مُختبر حيث أمكن)
CSP صارم بلا أصول خارجية للسكربت، nosniff، frame-deny، no-referrer، HSTS في الإنتاج،
rate limiting لكل مسار حساس، zod على كل مدخل، درع SSRF (بروتوكول/localhost/داخلي/metadata/
خصوصي عبر DNS/منع redirect/مهلة/حجم/نوع محتوى/stripHtml — 9 اختبارات)، سجلات بلا محتوى
مستخدمين مع redact()، كوكيز آمنة، وكلمات مرور scrypt.

## التحقق المنفذ
- **85/85 اختبار Vitest** تغطي: التصنيف (19 حادثة)، تدفقات المساعد الكاملة، محلل الروابط،
  درع SSRF، كل مسارات API، حماية الإدارة+CSRF، حد المعدل، محرك كلمات المرور، والتقييم.
- **فحص إنتاج حي:** البناء → `npm start` → الواجهة تخدم RTL من Express، المسارات العميقة
  تعمل، CSP حاضر، APIs تعيد 13 درساً و23 مورداً.
- **فحص متصفح حقيقي:** سطح مكتب 1280px (تخطيط RTL سليم، حروف عربية متصلة، بلا تداخل —
  بتقييم بصري مستقل)، جوال 390px (زر القائمة يظهر والتنقل يطوي)، ومحادثة كاملة حية:
  تصنيف صحيح ← سؤالان ← خطة كاملة بمراحلها وخطوات فقدان التحكم أولاً.

## غير مفعّل/محدود (بصدق)
| البند | الحالة | ما يلزم |
|---|---|---|
| فحص التسريبات | حالة «غير متاحة» صادقة | `HIBP_API_KEY` (اشتراك مدفوع لدى HIBP) |
| تحسين AI للصياغة | معطل افتراضياً | `AI_PROVIDER=openai-compatible` + مفتاح/موديل |
| البحث الحي في المصادر | البنية جاهزة، لا مزود بحث مهيأ | موصل مزوّل بحث + `RESEARCH_ENABLED=true` |
| توثيق روابط الموارد المتبقية | «بانتظار التحقق» | ضغطة زر «تحقق» لكل مورد من لوحة الإدارة |
| لغة إنجليزية ثانية | غير مترجمة | البنية جاهزة (محتوى مفصول) |

## التكاليف الخارجية المحتملة
- HIBP API: اشتراك مدفوع (~$3.5/شهر لأصغر باقة عند الكتابة) — إلزامي فقط لتشغيل فحص التسريبات.
- مزود AI (اختياري): بالاستهلاك؛ التكلفة على المشغل لا المستخدم (الرسائل محدودة الـtokens).
- Pwned Passwords range API: مجاني بلا مفتاح. لا شيء آخر خارجي.

## متغيرات البيئة المطلوبة
انظر `.env.example`. للإنتاج إلزامياً: `SESSION_SECRET` قوي و`ADMIN_PASSWORD` مخصص؛
الباقي اختياري بميزات تُعلن حالتها بصدق عند غيابه.

## خطوات النشر (مختصرة)
```bash
npm install && cp .env.example .env   # عدّل الإلزاميين
npm run build
NODE_ENV=production npm start         # خلف HTTPS (نقطة إنهاء TLS/بروكسي عكسي)
```
فحص الصحة: `GET /api/health` — أعد توجيهه لمراقبتك.
